# First From Scratch Website

A custom from-scratch real estate website I built for my mother. So far it is 99% HTML and CSS with the tiniest touch of JavaScript.
For now it's simple goal is to function as a place to direct and draw future clients. The CSS work was very much a trail by fire, and I'm sure there is a MUCH cleaner way to write it.
While that leaves the overall design questionable in places, I was very intentional about making the page highly accessible for all visitors including font readability, good contrast, aria-labels, alt text, and button functionality.
Embedding the videos via YouTube was seamless, and now a new content upload takes about 3 minutes to implement.
Still needs to be optimized for mobile and load time metrics improved.
I want to do MLS integration in the future, but for now access to necessary API credentials are not available to me.

Love you mom!
